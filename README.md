# 2023 산업연관표 분석 웹앱

한국은행 「2023년 산업연관표(연장표)」의 **대분류(33)·중분류(83)·소분류(165)·기본부문(380)** 투입산출표를 브라우저에서 불러와 산업구조, 연관효과, 최종수요 유발효과, 수요충격의 생산·소득·세수·고용 파급효과, 물가파급효과, 공급망 취약성, 두 산업 비교, 분류 수준 간 차이, 2020~2023년 추이를 분석하는 웹앱입니다.

- 게시 주소: 이 저장소의 Settings → Pages에 표시되는 주소 (형식: `https://계정이름.github.io/저장소이름/`)
- 과목: 산업조직론, 과제물1

별도 서버 없이 GitHub Pages에 정적 파일로 게시합니다. 계산은 방문자의 브라우저 안에서 Pyodide(WebAssembly 기반 Python)로 실행합니다.

## 1. 파일 구성

```
저장소 최상위/
|-- index.html                 화면과 입력·결과 영역 구성
|-- style.css                  화면 디자인
|-- app.js                     버튼 동작, 표·그래프 표시
|-- worker.js                  별도 작업 공간(Web Worker)에서 Pyodide 실행
|-- model.py                   Excel 읽기, 계수 검증, 산업연관 계산
|-- .nojekyll                  Jekyll 처리 없이 정적 파일 게시
|-- README.md                  프로젝트 설명과 사용 방법(이 문서)
|-- io-2023-33.xlsx            대분류(33부문) 투입산출표, 12개 시트
|-- io-2023-83.xlsx            중분류(83부문) 투입산출표, 12개 시트
|-- io-2023-165.xlsx           소분류(165부문) 투입산출표, 12개 시트
|-- io-2023-380.xlsx           기본부문(380부문) 투입산출표, 12개 시트
|-- sector-map.xlsx            부문분류표(기본부문 → 소분류 → 중분류 → 대분류)
`-- main-tables-2023.xlsx      주요표(2020~2023년 대분류 지표, 취업·고용계수)
```

웹 화면에서 폴더 없이 한 번에 올릴 수 있도록 Excel 파일도 최상위에 둡니다. 앱은 최상위에서 먼저 찾고, 없으면 `data/` 폴더에서 찾습니다.

각 투입산출표 워크북의 12개 시트는 다음과 같습니다. 총거래표·수입거래표·국산거래표, 총투입계수(A)·수입투입계수(Am)·국산투입계수(Ad), 생산유발계수·수입유발계수·부가가치유발계수, 최종수요 항목별 생산·수입·부가가치유발액.

## 2. 사용 방법

1. **자료 불러오기**: 분류별 버튼이나 「네 분류 모두 불러오기」를 누릅니다. 처음에는 Pyodide 준비에 수십 초가 걸리고, 기본부문 파일(약 12MB)이 가장 오래 걸립니다. 부문분류표와 주요표는 함께 자동으로 불러옵니다.
2. **분석 분류 선택**: 화면 위쪽에 고정된 「분석 분류」에서 불러온 분류 가운데 하나를 고르면, 2020~2023 추이(대분류 전용)와 분류 수준 비교(네 분류 동시 사용)를 뺀 모든 분석이 그 분류 기준으로 바뀝니다.

웹앱의 분석 기능은 모두 10가지입니다.

| 번호 | 기능 | 하는 일 |
|---|---|---|
| 1 | 원자료 탐색 | 12개 시트에서 행·열을 이름이나 코드로 검색해 원자료 값을 확인(예: 행 `9801` 영향력계수, 열 `9140` 수출) |
| 2 | 산업구조 분석 | 부문별 총산출·부가가치·중간투입률·국산화율·수입의존도·수출률. 행을 누르면 투입처·판매처 상위 10, 부가가치 구성, 승수, 소속 대분류의 2020~2023년 추이. 대분류·중분류에서는 산업 간 거래 히트맵(총·국산·수입 투입계수) |

| 4 | 연관효과 분석 | 영향력계수·감응도계수 산점도와 표로 핵심산업·후방연관·전방연관·독립 산업을 구분 |
| 5 | 최종수요 항목별 유발효과 | 소비·투자·수출 1원당 생산·부가가치·수입 유발과 10억원당 취업유발, 부문별 생산유발의존도 |

| 8 | 공급망 취약성 분석 | 수입품 하나를 고르면 부문별 직접·간접 의존도(원/1,000원)와 노출액(백만원) 순위. 원유·LNG·유연탄·철광석·집적회로·기초무기화합물 버튼 |

## 4. 분석 방법

기호: Z 중간거래, X 총산출, A = Z X̂⁻¹ 총투입계수, Ad 국산투입계수, Am 수입투입계수, L = (I − Ad)⁻¹ 생산유발계수, Âv 부가가치율 대각행렬, Yd 국산 최종수요.

### 4-1. 산업구조 지표 (총거래표·수입거래표)
- 중간투입률 = 중간투입계 ÷ 총투입, 부가가치율 = 부가가치계 ÷ 총투입
- 국산화율 = (중간투입계 − 수입 중간투입계) ÷ 중간투입계
- 수입의존도 = 수입 중간투입계 ÷ 총투입
- 수출률 = 수출 ÷ 총산출, 수입률 = 수입계 ÷ 총공급계, 중간수요율 = 중간수요계 ÷ 총공급계

대분류 계산값은 주요표의 2023년 값(예: 음식료품 중간투입률 76.5%, 국산화율 81.27%, 수입의존도 14.32%, 수출률 7.2%, 수입률 20.46%)과 일치합니다.

### 4-2. 연관효과
- 영향력계수(후방연쇄) = L의 j열 합 ÷ (열합의 평균)
- 감응도계수(전방연쇄) = L의 i행 합 ÷ (행합의 평균)
- 둘 다 1 이상이면 핵심(주도)산업, 영향력계수만 1 이상이면 후방연관 높음, 감응도계수만 1 이상이면 전방연관 높음, 둘 다 1 미만이면 독립(저연관)산업으로 분류합니다.

### 4-3. 최종수요 항목별 유발효과
원표의 「최종수요 항목별 생산·수입·부가가치유발액」 시트에서 열합(9819), 구성비(9812), 유발계수(9811)를 그대로 사용합니다. 항목별 생산유발액은 L·Yd로 다시 계산해 원표와 일치하는지 확인합니다. 부문별 생산유발의존도 = (항목별 생산유발액 ÷ 그 부문 생산유발액 합계) × 100.

### 4-4. 수요충격 시뮬레이션
국산품 최종수요 변화 Δf(백만원)에 대해 다음을 계산합니다.
- 생산유발 Δx = L Δf (간접효과 = Δx − Δf)
- 수입유발 Δm = Am L Δf
- 부가가치유발 Δv = Âv L Δf
- 취업유발 Δe = Ê Δx ÷ 1000 (Ê: 2023년 대분류 취업계수, 명/10억원)

비율 입력은 Δf_i = (부문 i의 기존 국산 최종수요 중 선택 항목) × 변화율로 환산합니다.

최종수요 항목별 취업유발계수(명/10억원) = Σ 취업계수 × 항목별 생산유발액 ÷ 항목별 국산 최종수요, 부문별 취업유발계수 = Ê L의 열(명/10억원)입니다. 중분류·소분류·기본부문에는 소속 대분류의 취업·고용계수를 적용하므로 취업·고용유발인원은 근사치입니다. 결과는 부문분류표로 상위 분류에 합산해 볼 수 있습니다.

### 4-5. 소득·세수 효과와 물가파급효과
- 부가가치 구성별 유발액 = Σᵢ (구성 항목ᵢ / 총투입ᵢ) × Δxᵢ. 구성 항목은 피용자보수, 영업잉여, 고정자본소모, 순생산세(생산세 − 보조금)입니다.
- 물가파급효과(레온티예프 가격모형): 가격을 지정한 외생 부문 K와 나머지 내생 부문 O로 나누어 Δp_O' = c_O' (I − Ad_OO)⁻¹로 계산합니다. 여기서 c = Σ Δpmᵢ·Am(i,·) + Σ Δp_k·Ad(k,·) + w·(피용자보수/총투입)입니다. 수입품 가격 변화는 수입투입계수를, 국내 가격 고정 인상은 국산투입계수를 통해 비용에 반영됩니다.
- 소비자물가 영향 = Σᵢ (민간소비 비중ᵢ × 가격 변화율ᵢ). 국산·수입 민간소비지출을 합한 구성비를 가중치로 쓰는 근사치입니다. 생산자물가 영향은 총산출 가중 평균입니다.
- 비용 상승이 모두 가격에 전가된다고 가정하므로 상한치로 해석합니다. 기본부문 기준 원유 수입가격 10% 상승은 소비자물가 약 0.21% 상승으로 계산됩니다. 대분류(광산품 전체에 적용)로 계산하면 0.49%로 과대추정되어 세분류 자료의 필요성을 보여줍니다.

### 4-6. 공급망 취약성·두 산업 비교·추이
- 공급망 취약성: 수입품 i에 대한 부문 j의 직간접 의존도 = (Am·L)ᵢⱼ, 직접 의존도 = Amᵢⱼ, 간접 의존도 = 둘의 차이입니다. 노출액 = (Am·L)ᵢⱼ × 부문 j의 국산 최종수요이며, 모든 부문의 노출액 합은 수입품 i의 중간재 수입액(수입거래표의 i행 중간수요 합계)과 같습니다. 웹앱은 이 항등식을 화면에 함께 표시하며, 네 분류의 모든 수입품에서 상대오차 1e-14 이하로 일치함을 확인했습니다.
- 두 산업 비교: 총거래표·수입거래표·유발계수표·항목별 생산유발액에서 두 부문의 지표를 계산해 나란히 보여줍니다. 「B ÷ A」 열은 두 값의 배율입니다.
- 2020~2023 추이: 주요표의 대분류 부문별 값과 전산업 값을 그대로 사용합니다(수출률·수입률은 구성비와 번갈아 있는 열 가운데 비율 열).

### 4-7. 분류 수준 비교
선택한 기본부문이 속한 부문의 생산·부가가치·수입 승수(L, 수입유발계수, 부가가치유발계수의 열합)와 영향력·감응도계수를 네 분류에서 비교합니다. 분류가 거칠수록 투입구조가 다른 산업이 한 부문으로 합쳐져 승수가 평균화되는 집계편의가 나타납니다. 예를 들어 기본부문 「벼」의 생산승수는 1.362이지만 대분류 「농림수산품」은 1.964입니다.

### 4-8. 자료 검증
불러올 때 다음 항등식을 다시 계산합니다. 최대 절대 잔차가 1e-6을 넘으면 불러오기를 멈춥니다(실제 잔차는 약 1e-14 이하). 결과는 「계수 검증 결과」에서 볼 수 있습니다.
- (I − Ad) L = I
- Am L = 수입유발계수, Âv L = 부가가치유발계수
- Z ÷ X = 총투입계수, 행 총산출 = 열 총투입
- 재계산한 영향력·감응도계수 = 원표 값
- L · Yd = 최종수요 항목별 생산유발액

국내 생산이 0인 부문(기본부문의 천연고무·유연탄·원유·천연가스(LNG)·원당, 소분류의 원유 및 천연가스)은 비율을 0으로 표시합니다.

## 5. 한계
- 투입계수가 고정되어 있고 공급 제약이 없다고 가정합니다. 가격 변화, 규모의 경제, 생산능력 한계는 반영하지 않으므로 단기·소규모 충격에 적합합니다.
- 생산자가격 기준입니다. 소비자가격 기준 수요를 넣을 때는 유통마진·운임을 먼저 빼야 합니다.
- 취업·고용 효과는 대분류 계수를 적용한 근사치입니다.
